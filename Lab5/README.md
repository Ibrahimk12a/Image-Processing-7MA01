# Lab 5: Spatial Filtering – Smoothing and Sharpening

In this lab, I did three main tasks using OpenCV:
* **Smoothing (Box Filter):** Convolved an image with a 7x7 box filter to blur it.
* **Smoothing (Gaussian Filter):** Applied a 5x5 Gaussian filter and a 21x21 Gaussian filter to compare different blurring intensities.
* **Sharpening (Laplacian Filter):** Applied a 3x3 Laplacian filter to sharpen a grayscale image.
