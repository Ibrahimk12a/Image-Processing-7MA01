# Lab 10: Image Segmentation and Feature Extraction

## Overview
In this lab, I used Python and OpenCV to explore image segmentation and feature extraction techniques.

## What I Did and learned 
- Applied **Canny Edge Detection** to detect edges in an image.
- Used **Harris Corner Detection** to identify corners in a checkerboard image.
- Applied **Global Binary Thresholding** using a fixed threshold value.
- Used **Otsu's Thresholding** on the coins image and displayed the original image, histogram, and thresholded image.
- 
This lab helped me understand how to detect edges and corners, and how Otsu's method can automatically choose a threshold for image segmentation.
